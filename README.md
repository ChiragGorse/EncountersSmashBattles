# Encounters Smash Battles (clone)

3D Smash-style brawler in Three.js. Open `index.html` in a browser (no build step).
Knock opponents off the stage; instead of health you have a knockback multiplier that climbs as you get hit.

Controls: WASD move · Space jump (x2) · Shift shield · J sword · Q/E camera · K/L/U/I abilities.

- **Mai**: K spin · L invisibility · U drop hat / press again to teleport · I throw card / press again to teleport to the stuck target
- **Brave**: K stunning chain · L jump + slam · U thrust · I fireball

Shield has its own health: it drains while held and when hit, and breaking it stuns you.
